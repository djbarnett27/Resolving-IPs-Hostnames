This script can be used in a corporate or home environment with access to DNS servers. 
The purpose of this script is to assist users with resolving a list of IP addresses to their respective hostnames, or vice versa.
The user is required to supply a list of one or more IP addresses and/or hostnames (fully qualified hostnames may be required) without any blank lines between them. 
The input stops once a blank line is detected when included in the initial data was entered, or by hitting the enter key.
Next, the user will select the type of query to be executed, or can quit the program.
Finally, the output displays the DNS forward or reverse lookup information.
