This script can be used in a corporate or home environment with access to either internal or external DNS servers. 
The purpose of this script is to assist users with resolving IP addresses to their respective host names, or vice versa.
The user is required to supply one or more IP addresses and/or host names (fully qualified host names may be required) without any blank lines between them. 
The input stops once a blank line after user presses the enter key.
The script will run and display the DNS forward or reverse lookup information.
